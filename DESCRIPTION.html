Saffron language support for JetBrains IDEs: IntelliJ IDEA, WebStorm, PyCharm, Rider, and the rest, including Community editions.

Saffron is an end-to-end test runner for the web where you write tests in plain language, with no step definitions and no glue code. The first time a scenario runs, an AI agent drives a real browser and records what it did; every run after that replays the recording at zero AI calls and zero tokens. When the UI changes, the agent heals the step mid-run and files a proposal you review, and Then steps are never healed. .saffron is Saffron's own test language: it reads your .feature files too, and goes further than Gherkin with StepSet: for reusable step groups, {env:VAR} tokens that keep secrets out of recordings and reports, and {data:...} references to your data files.

This plugin gives you, out of the box:

  • Syntax highlighting for .saffron files: Gherkin keywords, StepSet definitions and invocations, tables, doc strings, parameters.
  • Completion with status badges: every step the project knows, marked recorded (replays free), divergent, or unrecorded, so you reuse wordings instead of paying for near-duplicate recordings.
  • StepSet completion, go-to-definition and hover: jump from an invocation to its definition, even across files.
  • Diagnostics: unknown or duplicate set names, a set name missing the StepSet keyword, near-duplicate step wordings.
  • Run configurations: a Saffron entry under Add New Configuration (run files, folders or tags, replay-only, headed, re-record; open the report; accept proposals; open the execution replay of a scenario), and right-click → Run on any .saffron file or folder.
  • Saffron tool window with Files, Last Run, Proposals, Tags, Health, Orphans and Dashboard tabs: feature files with scenario counts and Run Selected / Run All; what failed in the last run, with a screenshot of the page one double-click away and Open Replay to step through the run in your browser, the page inspectable at every action (with saffron-ai 0.9.0 or later); proposals to tick, read and accept or reject; tags to tick and run; vocabulary health (divergent steps, near-duplicate wordings) and the effective config; recordings no scenario owns any more, removable in one action; and the run report embedded in the IDE.

Intelligence is served by saffron lsp from the saffron-ai npm package (npm i -D saffron-ai in your project) through the free LSP4IJ plugin. Install LSP4IJ to switch them on; highlighting, run configurations and the tool window need nothing else.
