Saffron language support for JetBrains IDEs: IntelliJ IDEA, WebStorm, PyCharm, Rider, and the rest, including Community editions.

Saffron is an end-to-end test runner for the web where you write tests in plain language, with no step definitions and no glue code. The first time a scenario runs, an AI agent drives a real browser and records what it did; every run after that replays the recording at zero AI calls and zero tokens. When the UI changes, the agent heals the step mid-run and files a proposal you review, and Then steps are never healed. .saffron is Saffron's own test language: it reads your .feature files too, and goes further than Gherkin with StepSet: for reusable step groups, {env:VAR} tokens that keep secrets out of recordings and reports, and {data:...} references to your data files.

This plugin gives you, out of the box:

  • Syntax highlighting for .saffron files: Gherkin keywords, StepSet definitions and invocations, tables, doc strings, parameters.
  • Completion with status badges: every step the project knows, marked recorded (replays free), divergent, or unrecorded, so you reuse wordings instead of paying for near-duplicate recordings.
  • StepSet completion, go-to-definition and hover: jump from an invocation to its definition, even across files.
  • Diagnostics: unknown or duplicate set names, a set name missing the StepSet keyword, near-duplicate step wordings.
  • Run configurations: a Saffron entry under Add New Configuration (run files, folders or tags, replay-only, headed, re-record; open the report; accept proposals; open the execution replay of a scenario), and right-click → Run on a .saffron or .feature file or folder in the project's test folder (features in saffron.config.json), or inside a scenario to run that scenario alone. With LSP4IJ, ▶ Run scenario, Replay only and Headed sit above each scenario (with saffron-ai 0.9.8 or later).
  • Saffron tool window with Files, Last Run, Proposals, CI Runs, Tags, Health, Orphans and Dashboard tabs: the test folder's feature files with scenario counts and Run Selected / Run All; what failed in the last run, with a screenshot of the page one double-click away and Open Replay to step through the run in your browser, the page inspectable at every action (with saffron-ai 0.9.0 or later); proposals to tick, read and accept or reject; the current branch's GitHub Actions or Azure Pipelines runs; tags to tick and run; vocabulary health (divergent steps, near-duplicate wordings) and the effective config; recordings no scenario owns any more, removable in one action; and the run report embedded in the IDE.
  • Review a heal made in CI: CI Runs lists the branch's runs, says what each run left to view (GitHub), shows what a selected run found without importing it (its failed and pending-review scenarios, its report and replays, with saffron-ai 0.9.7 or later; a browser matrix's rows labelled with their browser, with 0.9.9 or later), and with saffron-ai 0.10.0 or later shows the selected run as one page below the runs: the totals, each failed and pending-review scenario as a card with its screenshot, failing step and error, and the proposals. Import Run brings a run's proposals into your checkout, checked against your files, and you accept or reject them in Proposals like your own (needs saffron-ai 0.9.3 or later, with gh or az signed in).

Intelligence is served by saffron lsp from the saffron-ai npm package (npm i -D saffron-ai in your project) through the free LSP4IJ plugin. Install LSP4IJ to switch them on; highlighting, run configurations and the tool window need nothing else.
