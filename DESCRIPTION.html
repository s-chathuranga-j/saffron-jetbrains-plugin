Saffron language support for JetBrains IDEs: IntelliJ IDEA, WebStorm, PyCharm, Rider, and the rest, including Community editions.

Saffron is a Gherkin-native end-to-end test runner: an AI agent records each scenario once, every later run replays at zero tokens. Its .saffron files are plain Gherkin plus the StepSet: keyword for reusable step groups.

This plugin gives you, out of the box:

  • Syntax highlighting for .saffron files: Gherkin keywords, StepSet definitions and invocations, tables, doc strings, parameters.
  • Completion with status badges: every step the project knows, marked recorded (replays free), divergent, or unrecorded, so you reuse wordings instead of paying for near-duplicate recordings.
  • StepSet completion, go-to-definition and hover: jump from an invocation to its definition, even across files.
  • Diagnostics: unknown or duplicate set names, a set name missing the StepSet keyword, near-duplicate step wordings.
  • Run configurations: a Saffron entry under Add New Configuration (run files, folders or tags, replay-only, headed, re-record; open the report; accept proposals), and right-click → Run on any .saffron file or folder.
  • Saffron tool window with Files, Proposals, Tags, Health and Dashboard tabs: feature files with scenario counts and Run Selected / Run All; proposals to tick, read and accept or reject; tags to tick and run; vocabulary health (divergent steps, near-duplicate wordings) and the effective config; and the run report embedded in the IDE.

Intelligence is served by saffron lsp from the saffron-ai npm package (npm i -D saffron-ai in your project) through the LSP4IJ plugin, which is installed alongside. Highlighting needs nothing else.
